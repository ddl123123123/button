# 钮扣索引

一个用图像和词语两种方式检索钮扣的网站。

- 图像视图：钮扣沿一条弧线排开，滚动、拖动或用方向键翻看。
- 词语视图：点一枚钮扣，看到描述它的词语（材质、颜色、形制、工艺、年代、产地、用途、纹样）以及和它共用词语的其他钮扣；点一个词，看到所有带这个词的钮扣。

在线地址：https://ddl123123123.github.io/button/

## 本地运行

纯静态页面，没有构建步骤。在项目目录里起一个本地服务器即可：

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173 。

## 换成自己的钮扣

- 钮扣和词语都在 `data.js` 里，文件开头有说明。
- 钮扣照片放进 `images/`，在 `data.js` 对应那一行的最后一格写上路径；白底会自动抠掉。没有照片的钮扣会用程序画的占位图。
- 配色集中在 `style.css` 开头的六个值和 `data.js` 里 `TYPES` 的八个类别色。`palettes.html` 是当时比较配色方案用的预览页。
